# Hunter Research Library

## Purpose

This library contains external research that may improve Hunter.

Examples include:

- YouTube transcripts
- Books
- White papers
- Academic research
- Trading observations
- Market studies
- Institutional concepts
- Personal discoveries

Nothing inside this library is automatically part of Hunter.

Research must be evaluated before being incorporated into:

- Constitution
- Decision Framework
- Core Engines
- Runtime

Every research paper should answer four questions:

1. What did we learn?
2. Should Hunter adopt it?
3. Which engine would it improve?
4. What priority should it receive?

This library serves as Hunter's long-term institutional knowledge base.
